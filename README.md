# Экзамен-Тренажёр

## Структура

- `index.html` — разметка страницы.
- `css/styles.css` — стили и адаптивная раскладка.
- `js/data.js` — предметы, теория и вопросы.
- `js/app.js` — интерфейс, состояние и обработчики событий.
- `js/quiz.js` — логика прохождения тестов и сохранение результатов.
- `assets/favicon.svg` — иконка сайта.

## Запуск

Из этой папки запустите локальный HTTP-сервер:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/` в браузере. Сервер необходим для загрузки ES-модулей.
