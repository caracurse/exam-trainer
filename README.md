# Экзамен-Тренажёр

Веб-приложение для подготовки по географии и биологии: теория, поиск по материалам, тесты с объяснениями и итоговая статистика. Проект работает в браузере и не требует сборки, установки npm-пакетов, базы данных или сервера приложения.

## Возможности

- Два предмета с шестью тематическими разделами, 52 теоретическими материалами и 59 заданиями.
- Просмотр теории по разделам, раскрытие ответов и поиск по вопросам и текстам ответов.
- Настройка теста: выбор разделов, количества вопросов и перемешивания.
- Учебный режим с объяснением после каждого ответа и экзаменационный режим с разбором в конце.
- Таймер, пропуск вопроса в экзаменационном режиме, оценка и статистика по разделам.
- Повтор теста, отдельная проработка ошибок и история последних попыток.
- Светлая и тёмная темы, адаптивная раскладка для мобильных экранов.

## Требования

- Современный браузер с поддержкой JavaScript ES-модулей и `localStorage`.
- Локальный HTTP-сервер для запуска. Прямое открытие `index.html` через `file://` не подходит: браузер блокирует загрузку ES-модулей.
- Интернет для загрузки Bootstrap Icons с CDN. Остальная логика и материалы хранятся в файлах проекта.

Сборщик, Node.js и установка зависимостей не нужны.

## Быстрый запуск

Откройте терминал в папке `проект` и запустите сервер Python:

```powershell
python -m http.server 8000
```

Если команда `python` не найдена в Windows, попробуйте:

```powershell
py -m http.server 8000
```

Откройте в браузере <http://localhost:8000/>. Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl+C`.

Можно использовать любой локальный статический HTTP-сервер. Запускайте его из корня проекта, где находится `index.html`, чтобы относительные пути к `css/`, `js/` и `assets/` разрешались правильно.

## Как пользоваться

1. На главной странице выберите предмет.
2. На вкладке «Теория» раскрывайте вопросы или ищите по словам из вопроса и ответа.
3. Перейдите на вкладку «Тест» и выберите разделы, число вопросов и режим.
4. Нажмите «Начать тест», выберите вариант и переходите к следующему вопросу.
5. На экране результатов изучите оценку, статистику по разделам и разбор ответов.

Доступные размеры теста: 5, 10, 15, 20 или все вопросы из выбранных разделов. Количество ограничивается числом заданий, которые действительно доступны.

В учебном режиме правильный ответ и объяснение показываются сразу после выбора. В экзаменационном режиме ответ можно выбрать или пропустить, а подробный разбор появляется в итогах. В конце теста можно начать его заново, пройти только ошибки, вернуться к теории или открыть главную страницу.

### Клавиатура

- `1`–`6` — выбрать соответствующий вариант ответа.
- `Enter` — перейти дальше после выбора ответа.

## Структура проекта

```text
проект/
├── index.html          # HTML-оболочка, подключение стилей и главного модуля
├── README.md           # эта инструкция
├── assets/
│   └── favicon.svg      # иконка вкладки браузера
├── css/
│   └── styles.css      # оформление, темы и адаптивные правила
└── js/
		├── data.js         # предметы, разделы, теория и задания
		├── app.js          # состояние, экраны, рендеринг и события интерфейса
		└── quiz.js         # логика теста, таймер, результаты и история
```

`app.js` импортирует данные из `data.js` и контроллер теста из `quiz.js`. В HTML подключается только `js/app.js` как ES-модуль; дополнительные модули загружаются через `import`.

## Изменение учебных материалов

Откройте `js/data.js`. Экспортируемая константа `DATA` содержит предметы. Каждый предмет включает идентификатор, название, описание, цвета, класс иконки и массив `sections`.

Раздел содержит:

- `id` — уникальный идентификатор, например `g1` или `b2`;
- `short` — короткое название для фильтра теста и статистики;
- `title` — полный заголовок раздела;
- `theory` — массив теоретических материалов;
- `quiz` — массив заданий.

Формат элемента теории:

```js
{ q: 'Вопрос?', a: 'Текст ответа.' }
```

Формат задания:

```js
{
	q: 'Текст задания?',
	o: ['Первый вариант', 'Второй вариант', 'Третий вариант', 'Четвёртый вариант'],
	c: 0,
	e: 'Пояснение к правильному ответу.'
}
```

`q` — формулировка, `o` — варианты ответа, `c` — индекс правильного варианта с нуля, `e` — объяснение. Индекс `0` означает первый вариант. Для вопросов используйте не более шести вариантов, так как клавиатурный выбор ограничен клавишами `1`–`6`.

Если добавляете новый предмет или раздел, проверьте, что его `id` уникален. Количество материалов на карточках предметов вычисляется по `DATA`; общие показатели «2 предмета» и «6 разделов» на главном экране заданы в `js/app.js` вручную и требуют обновления при изменении числа предметов или разделов.

В ответах теории допускается HTML-разметка для форматирования текста. Используйте только доверенное содержимое: ответ теории вставляется в страницу как HTML.

## Состояние и сохранение

Настройки и результаты хранятся в `localStorage` текущего браузера и origin. На сервер данные не отправляются.

- `examTrainerTheme` — выбранная тема.
- `examTrainerHistory` — до 20 последних результатов; на главной показываются до пяти.

История не синхронизируется между браузерами или устройствами. Очистка данных сайта в настройках браузера удалит сохранённую тему и историю.

## Публикация на GitHub Pages

Текущий сайт опубликован по адресу <https://caracurse.github.io/exam-trainer/>. Pages настроен на публикацию корня ветки `main`. Сборка не нужна: после отправки изменений в эту ветку GitHub Pages автоматически обновляет сайт.

При переносе проекта в другой репозиторий укажите в его настройках **Settings → Pages → Deploy from a branch**, выберите `main` и папку `/ (root)`. Дождитесь успешного workflow `pages build and deployment` во вкладке **Actions**.

## Частые проблемы

- **Страница открыта, но данные или модули не загрузились.** Запустите HTTP-сервер из корня проекта и откройте адрес `http://localhost:8000/`, а не файл `index.html` напрямую.
- **Не отображаются значки.** Bootstrap Icons загружается с jsDelivr; проверьте подключение к интернету и доступность CDN.
- **Нет истории или темы после перехода по другому адресу.** `localStorage` привязан к origin. `localhost`, GitHub Pages и локальный файл имеют разное хранилище.
- **На GitHub Pages отображается старый сайт или ошибка.** Проверьте, что изменения отправлены в `main`, источник Pages указывает на `/ (root)`, а последний workflow завершился успешно.
